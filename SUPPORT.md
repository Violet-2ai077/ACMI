# Support

- **Usage:** start with [Getting Started](docs/getting-started.md) and the
  [dsh Quick Start](examples/dsh-quickstart/README.md). Use repository Discussions
  if enabled; otherwise open a usage question in [GitHub Issues](https://github.com/Violet-2ai077/ACMI/issues).
- **Bugs:** search [GitHub Issues](https://github.com/Violet-2ai077/ACMI/issues)
  first. Include version, OS, expected and actual behavior, and a synthetic
  reproduction. Never attach credentials, raw session logs, or private files.
- **Feature requests:** open a GitHub issue describing the use case and the
  runtime capabilities required. Check the [Roadmap](ROADMAP.md) first.
- **Security:** follow [SECURITY.md](SECURITY.md). If no private maintainer
  channel is available, use an issue only to request private follow-up, with no
  report details or attachments.
