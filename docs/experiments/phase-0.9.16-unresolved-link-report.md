**结论：`PASS_HOST_MODEL_GATE_NOT_MET`。** Host 能安全解释显式引用，但本批模型一次都没有使用。Assistant 归属无改善，User 归属反而下降。保留实验性的只读 WorkAnchor 与建议侧车，不启用自动路由，不扩大到 Streaming、Tool Calling 或 Subagent 资格验证。

## 实验与隔离

基点 `e7d1500fff9d2ff03f9b409171c55b0a325a00b7`，推理前冻结提交 `75c304483d879a0e23865d66038c9a4868b0597f`。[预注册](../qualification/phase-0.9.16-unresolved-link-preregistration.md) 固定 12 个新合成配对、24 个独立原生 Session。A 使用 0.9.15 B 原合同；B 只在 Assistant 主归属的 schema 和提示中添加 `same_unresolved_as_user`。同对候选、位置、Handle、用户输入、锚点均相同；两臂各显示五个有效锚点。四个既有目标覆盖四个候选位置。未重复使用 0.9.15 的模型输出。

该关系只引用同次 completion 中明确且有效的 User `unresolved`，并要求 `clarify` 意图；不引用 Host fallback、旧请求、别的 Session 或已选锚点。缺失、非法或非未决来源时，模型原始引用判为无效，即使 Host 降级到 `unresolved` 也不计模型正确。离线测试通过了有效关系、非法来源、额外字段、重复键、截断、工具禁用、泄漏和评分门槛检查。

使用原 Qwen3-14B Q4_K_M、llama.cpp b12283 Vulkan、RTX 3060、隔离 stock dsh 0.2.2-rc.1。五项模型和运行时摘要匹配；24/24 原生完成、24/24 锚点回执、24/24 同次完成对账、24 个独立后端生成起点，零重试。自有回环端口 10586 已退出。原始记录留在实验侧车，未泄漏到正文或隔离 Journal；无越界写入、工具动作、云端请求。没有修改已安装 dsh 或原始 Journal、自动 Binding、写 Graph、接受子结果或满足 Join。真实模型批次不挂工具，原生适配器的完整帧投影不是真正逐 token Streaming。已有的晚到结果仍按原始 Tool Call 归属，不改因果规则。

- 两臂在五个身份澄清样本均给出了正确的 User 状态和意图，但 Assistant 标签完全相同：同名案例各自错指一个既有 WorkNode，其余四例都是 `no_task`。B 的新选项出现在实际已核对的冻结请求中；没有观察到一次尝试，也没有观察到 Host 拒绝。不能把这归因为 Host 丢弃关系，不能由本批断言其他提示、顺序或模型也不会使用。
- B 在明确续接与明确切换中都将 User 降为 `unresolved`，Assistant 仍选对正文所指任务，造成两个配对退步。既有工作细化两臂 User 均错，但 A 提了新目标、B 标为未决；已知任务的细节澄清两臂归属均正确。
- 正文只按冻结词组和问号判定。例如 B 的同名案例问了「哪一版」但没列出两版；另三个 B 回答以「请告诉我哪一个」等祈使句请求补充，未通过问号门槛。不能把 1/5 等同于只有一次实质澄清，也不能把正确正文算作标签正确。未用模型 Judge。合成英文样本及两个角色在真值上仍共享主主题，本结论不外推到任意会话。
