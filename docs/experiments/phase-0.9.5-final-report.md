## 决策与下一步

- 0.9.4 人工资格仍为 BLOCKED；0.9.5 不以全量人工为契约门槛，但也不把结构 oracle 或 LLM 互评当用户真值。Provider 请求、凭据访问、真实 Session 访问均为 0。
- 先做两个小规模配对轨：在固定候选下改变是否提供最短授权前文证据；在固定证据下比较解析器。允许自动生成变体，但报告簇数、正控覆盖和错误选中。不要仅扩 Top-k，也不要用旧开放 Validation 调后再当独立验收。
- 后续如获真实 Provider 单独授权，用干净的包投影对比规则与 LLM；评审返回证据与不可判定，保留分歧，不用多数票生成真值。先验证非结构化的解析/澄清收益，再讨论只读展示；不会自动绑定、Apply、接受 Result、满足 Join 或关闭任务。
- 真实使用反馈暂不采集。以后需单独授权和隐私审查，只认明确选择、纠正或取消，绝不把沉默、继续聊天、模型自己回填或已绑定状态算确认。建议数据最小化为作用域内短期 receipt ID、动作枚举、版本和聚合分母；不要存用户原文，也不要为拿到反馈而改写 Journal。
