# Phase 0.9.1 stock dsh runtime shadow

Use the pinned isolated stock dsh 0.2.2-rc.1 with a local scripted Agent
adapter and the Phase 0.8.2 Supervisor. After durable drain, the trusted Host
may explicitly request Shadow on one exact authorized Session cut, with
up to 32 new metadata facts and the Phase 0.9 structure compiler. The
optional excerpt source is a keyed synthetic fixture, not a Journal scan.
The four non-adversarial offline modes run on the same committed cut; the
call returns proposals and receipts in memory, never a graph writer.

The Source/Built test exercises A/B/A, an interruption, a different Session,
a real stock child turn, correction, no-task and ambiguous cues, objective
change, similar candidate collision, missing candidate and foreign denial.
It compares native Journal byte hashes and scoped Graph cuts immediately
before and after Shadow. Native runtime itself still appends its normal
synthetic events before the comparison. No automatic apply, no Provider
transport, no production context injection. This tests integration behavior
and invariants, not natural-language accuracy on real users.
