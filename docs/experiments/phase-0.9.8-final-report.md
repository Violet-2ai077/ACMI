## 决策与限制

- 不接入产品、不启用自动绑定、不把规则换成此模型配置。偏差同时来自证据格式和语义/弃权；只修 UTF-16 坐标并不能补足模型的选择质量。
- 若再试，先用另行预注册的开发对照拆开两处：模型只返回来源与原文摘录，Host 唯一匹配后计算坐标；输出合同用互斥分支硬约束「澄清/无建议 ⇒ null handle」。仍需另测语义和弃权，使用新的独立验证故事，不能重跑本批来证明提升。
- 临时服务绑定 127.0.0.1，未设局部访问 token；运行时提示 CORS 宽松。本机日志生成次数与 ledger 一致，没有观察到额外生成。若未来长时运行，应用一次性本机访问认证而不是把当前隔离视为访问控制。本轮不保留监听服务。
- 仅比较一个模型、一个量化/模板配置和小规模开放数据，不外推到其他模型。没有 Push、Release 或 Phase 1.0。

见[复现手册](../runbooks/phase-0.9.8-local-model-reproduction.md)。只复放 scorer 和诊断，不再次推理；原始合成响应、账本、预算和结果均有摘要。
