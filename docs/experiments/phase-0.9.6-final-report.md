## 边界与失败

518/518 控制通过。拒绝未授权、不完整、非用户、跨 Workspace/Session/incarnation、过期、伪造正文、超过字节或估算 token 预算的来源；拒绝结果不带前文。前文关闭不调用来源读取。将有效的前文明确换指另一任务时，身份随证据变化，而不是跟着旧 Binding；目标不在授权候选时保持弃权。已关闭任务只在查阅模式产生历史引用，不能作为活跃建议。

Host 在读取前后确认 Scope、来源许可和版本、整条原文 SHA；SHA 不单独证明来源真实。前文允许披露须由可信 Host 另行确认，不能把「在同 Session」当成权限。当前限制仅同 Session 紧邻事件，不做任意前文检索，也未测试真实数据。两臂共享基础包哈希；若额外前文超总预算就不投影，不驱逐候选。已授权的用户正文提到某个任务名不等于获取该任务；任务 ACL 仍需单独检查。

未解决的 4 个正例是 3 个不使用精确名称的自然改述和 1 个不符合有限语法的否定对照。增加前文解决的是**看不到证据**的部分，并没有解决**看到了但不会读懂**的问题。基准对照是离线规则，不是 LLM 能力对比；不建议继续叠加正则追逐这 4 条。
