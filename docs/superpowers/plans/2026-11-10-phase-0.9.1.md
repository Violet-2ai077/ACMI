# Phase 0.9.1 Implementation Plan

> For execution: keep the approved autonomous workstreams isolated, and freeze the evaluator before running the reserved holdout.

**Goal:** Qualify natural-language task proposals independently from the safety of applying them.

**Architecture:** Author separate provisional dialogue pools; score predictions independently of evidence validation. Extend the existing trusted Host review transaction with versioned protected synthetic sources. Use a bounded scoped catalog and an offline-only evaluator. Keep explicit Task lifecycle commands separate from inference and shadow evaluation.

**Tech stack:** TypeScript, Node SQLite, stock isolated dsh, Vitest, Node CLI, PowerShell packaging.

1. Verify original archive, base and baseline. Author split-specific cases without evaluator access to labels.
2. Add failing tests for stale/foreign/incorrect evidence, Decision confirmation, Result content and Dependency direction. Implement the grounded claim verifier and recheck it in the durable Host review.
3. Add bounded and revocable candidate ranking, explicit Task lifecycle and offline JSON schema/timeout harness with red-green tests.
4. Build role-aware scoring, annotation exports, and single-run holdout lock. Tune only on the open development/validation corpus.
5. Exercise shadow evaluation from authorized native dsh facts with no write surface. Run all old benchmarks, regression and an independent local clone.
6. Commit exact paths locally, generate the evidence bundle, and independently extract/verify hashes. Do not push or use real Providers.
