# 四种 Task Understanding 架构比较

控制变量：同一授权读视图、证据验证、不可自动写入、同一新语料与正/负例分母；不拿有更多信息的实现对照少信息实现后归因模型。逻辑层数和推理调用次数分开。评分 1（不利）至 5（有利），非基准分或权重加总。S=现有代码边界能直接支持，I=对结构的可检验推断，J=工程判断；原型直接观察单列，避免把它外推为全轴评分。

A 把全部输出一次收回，无状态时便于部署和重放，但单个 “switch+ID+graph” 标签会混合检索、分类和证据错误。保留 A 作为共同 safety gate 的直接对照，不意味着 A 必须写 store 或只能使用长历史。B 的好处是类型化错误和独立弃权，风险是上游误判级联和串行成本；可以一次逻辑分层回答，再选择是否补问，不强制三个模型阶段。C 只把带引用的信念状态带入下一个事件，长序列较有利；必须解决过时、并发和重放，不能把上一次猜测变成事实。D 用可信事件触发并在需要时使用 C+B，不按关键词跳过用户正文；弱点是遗漏相关事件、复杂度更高和可能污染状态。用 shadow sampling 跟踪 skip 的误差，定期对比「所有事件分析」并可回退到 B/只读观察。

离线直接观察见 [原型比较](phase-0.9.2-offline-prototype-comparison.md)：原型只测独立新合成数据和 mock 条件下的信息流、调用/字节成本、可解释失败；未测外部模型、真实模型时延与生产成本。A/B/D 对照不能归因于某一个跨层变化；分别用无触发、无记忆、无运行事实消融定位。

**P（prototype-measured，仅针对样例）**：Validation 中，硬触发 D 将候选比较从无触发的 40 次降到 33 次，但只触发 14/17 个需要分析的事件，路由+身份 exact 从 23/25 降到 20/25。因此矩阵第 11 项的潜在成本优势不能抵消召回损失；D 的推荐策略是避免硬关键词触发，保留无触发控制。开发样例无记忆的 exact 18/21（对照 19/21），差值仅一个回指；不能外推第 5–7 项的收益。

**推荐 D 的研究路径，不承诺部署。** 默认一次有界分析；仅在缺有效引用或需要澄清时一次窄域补取，不允许反复“猜到确定”。维护共享的 layered 输出/authorization fence，以支持 B 降级。将减少过度弃权和避免误 apply 分为不同门槛，并报告风险-覆盖曲线；指标框架参考 [Selective Classification for Deep Neural Networks](https://proceedings.neurips.cc/paper/2017/hash/4a8423d5e91fda00bb7e46540e2b0cf1-Abstract.html)，其原论文实验不证明 ACMI 风险可控。若无法证明触发完整性、状态隔离或资源界限，保留只读 B，不用更多规则掩盖未知项。
