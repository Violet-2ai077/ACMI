# Reviewer A/B 入门与分发

协调员先验收两名不同真人及无利益冲突，留私有核验记录。仅分别交付该 lane 的 packet、label guide、annotation schema 和空 template；**不能分发整份交付 ZIP**。不要给 reviewer 另一包、映射、Gold、预测、split、风险标签或结果。两位独立完成，禁止沟通、搜索语料或使用模型作答。先用非语料例子演练 UTF-16、身份弃权和 Tool 事实；不把演练并入正式评测。

读取 case ID、焦点 ID 和任务局部 ID。每 case 一条记录，填充分理由、相关的精确证据；不确定时说明，不猜。提交给协调员私有写入点，由本人填写真实匿名登记 ID、UTC 时间和 attestation；模板的 null 必须替换，工具不能替真人签署。收到后单独哈希归档原始文件。

当前两个包是可分发的开放流程演练材料，不是正式资格 Holdout，也未分发给任何人。开放盲包 ID 与顺序不同，但相同题面可交叉匹配；制度隔离不可由 hash 代替。
