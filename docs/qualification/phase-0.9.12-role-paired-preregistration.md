## 判定

- 协议：22/22 初始模型请求有同 completion 的安全可见正文和归属观测，A/B 各 10/10 基础轮正常完成，每臂至少 8/9 条回答断言通过；无泄漏/越界写入/未授权动作。原生 dsh 工具行为须保留：B、A 各 2/2 动作与 Result 因果正确，并正常总结。任一不通过独立报告。
- 语义：B User ≥8/10、Assistant primary ≥8/10；两者合计相对 A 至少多 2 个精确。既有 User 覆盖 ≥6/7，既有任务错指 0、把已有误判为新目标 0。B intent ≥9/10、3/3 多任务回答 related 精确、2/2 变体保持正确主归属。A 没有 intent/related 合同，记 N/A；不把不支持当作错误分母。
- 新目标（两臂）若声称归属正确，还须其描述含冻结的新目标名称。回答断言只测指定名称/值，不是自然语言全面评价。样本规模不足以外推生产；不对旧样本补跑，不以正确的工具归属替代错误的 Assistant 主归属，不事后放宽阈值。
- 不自动写 Graph、Binding、接受子结果或满足 Join。不测试真实 Subagent、跨 Session 召回或逐 token streaming。不 Push、不 Release，不进入 Phase 1.0。
