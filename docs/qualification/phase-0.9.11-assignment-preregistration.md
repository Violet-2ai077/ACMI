## 判定

- 协议门槛：16 个初始模型请求都分别保留原生可见正文与同 completion 的归属观测，12/12 原生完成，冻结回答断言至少 10/11，零 metadata 泄漏、零未授权动作、零 Graph/Binding/子结果接受/Join 修改；Source/Built 离线负例验证可安全拆分时正文不被无效归属吞掉。
- 语义门槛：基准 User 精确至少 9/12 且严格好于固定 Binding；9 个既有位置中覆盖至少 8，现有任务错指为 0；Assistant 精确至少 9/12。4/4 排列和改名保持同一正确选择。
- 工具门槛：两轮各两条原生动作，4/4 Task/WorkNode 正确，4/4 Result 按源调用因果继承；2/2 工具体完成逆序，4/4 到达观察都能匹配。未关联或不属于原调用的结果不按当前 Binding 回填。
- 三项分别报告，不用部分通过补全总体通过。小样本仅是这条路径的可行性。真实 Subagent、跨 Session 召回、真实 Token streaming、生产权限热更新不在本轮范围。
