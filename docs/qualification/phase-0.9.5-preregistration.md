# Phase 0.9.5 自动化身份建议验收协议 v1

基点：`7e03f90a702c134fd19b6719fb65d3d6ea725a44`。以本文件的首次 Git 提交冻结版本和时间，之后才构造基准和实现。0.9.4 的人工资格仍为 BLOCKED；本阶段不替换其门槛、不重用旧 Holdout，也不申报生产自动路由。

## 问题和两条证据轨

1. **可自动判定的契约测试**：用合成任务轨迹确定目标、授权、当前 cut、是否闭合和可见消歧证据；按预注册反事实导出预期。允许机械生成变体，因为测的是不变性/等变性，而不是独立自然语言场景。分别报告故事簇数和变体数。
2. **开放语言诊断**：允许重放已公开的 0.9.4 Dev/Validation，仅用于探索候选已在榜但仍解析失败的现象。结果保持作者 provisional；不当作新独立验证，不要求全量人审，不使用旧/新 reserve 或消耗任何 Holdout。

构造版本 `acmi-095-identity-traces-v1`；逐故事手写词句、确定性穷举变换，无随机种子。至少 20 个新故事簇，Dev/Validation 各至少 10；整簇和所有变体只在一侧；按构造簇而非变体计数。至少覆盖英文、中文和中英混合。Dev 以直接引用和基本授权快照为主；Validation 用不同故事验证冲突、历史只读、无前文证据及有/无经确认先行项。保留具挑战性的机制变体，不通过删除失败样本达标。

## 同输入比较和预期

- 基线：现有 0.9.3 分层规则在同一个有界 packet 上的身份输出；候选检索和理解分别评分，不用召回当解析质量。实验臂：默认关闭、显式启动、受限语法的只读建议。
- 正控：唯一、当轮、明确选择或只读查阅的任务锚点；或明确指向“刚确认的任务”且同 Session 上一个 cursor 有 Host 认证的显式用户选择。对照删除该证据、保留猜测或换成旧 revision，必须停止推荐。
- 不变性：候选重排、当前 Binding 反转、加入不匹配候选，不应改变有证据的目标。比较 stable task ID，不比较包内易变 handle。
- 反事实：同名撞车、去掉唯一线索、目录不完整或无权、陈旧、历史状态变化、工具/引用/条件/非选择文本。没有足够证据时返回 clarify/no_suggestion/unavailable；历史 ID 只读，不能成为活跃建议。
- 不使用“正确目标”或 split 作为包字段；基准期望独立于预测。合成确认来自 fixture Host，不冒充真人数据。

## 门槛与限制

自动契约验收最低分母：各 split 至少 10 个故事簇、Validation 至少 10 个符合明示锚点或有效确认的正控、10 个不应输出身份的负控，另至少 5 个配对不变性组。要求：合格正控的正确建议/历史引用覆盖 >= 90%；变换预期全匹配；错 Task、越权/陈旧身份输出、把闭合任务当活跃、持久化效果均为 0。任一违反禁止扩大使用范围。没有足够分母为 INCONCLUSIVE。报告输出率和正确率、无目标时的错误选中、弃权、每种变换和榜内条件准确率，不以全弃权通过。关联变体不计算 IID 置信区间，不推断生产风险率。

本阶段只验收窄合同，不承诺理解自由语言、真实使用效果或自动绑定。无真实 Provider 请求、凭据、外部评审或真实 Session；不接 Graph writer、不自动 Apply/接受 Result/满足 Join/关闭任务、不修改安装 dsh/原 Journal、不 Push、不发布 Release。未来 LLM 评审只作探索信号，不能冒充用户的实际指代。真实使用反馈需另行授权，只有显式选择/纠正/撤销是信号；不收集用户原文、不把沉默算同意。
