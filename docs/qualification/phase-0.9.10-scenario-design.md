# Phase 0.9.10 合成样本

生成器固定 6×4 Pilot、20×4 主样本、16 个附加排列。题面、授权候选、当前 Binding 和明确授权的合成 handoff 单独导出；另一文件保留 UUID、WorkNode、期望关系、工具调用、拒绝写入与响应断言。模型输入导出另含实验调度信息，但真正 wire 只发送筛选后的字段。

Pilot：两组同 Session A/B/A；跨 Session handoff；近似名称、不同交付物；负向/含糊；最后一个故事末轮两条工具动作。主样本另外含 A/B/C/A、新目标/修订、暂停、历史关闭、Binding 冲突、多任务相关关系、纠正、缺失和未授权 Handle。主样本的子代理情境只测试文本计划，不启动代理；真实执行标识和乱序关联由离线因果测试覆盖。没有原生实时跨 Session 结果派发或生产召回实验。

同一 Story 的任务 ID 固定，Session 按合成序列切换。变换比较不是独立样本。新故事与历史 0.9.9 样本不混用。
