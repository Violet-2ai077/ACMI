# Phase 0.9.16：同次生成未决主题引用（预注册）

基点 `e7d1500fff9d2ff03f9b409171c55b0a325a00b7`。0.9.15 修复了两个真实新目标，但三个身份澄清样本均未做到双角色正确。本次比较「两个角色独立标记」与「Assistant 可显式引用 User 未决主题」，不比较提示、历史检索或锚点机制的其他改动。

## 固定设计

- A 是原样的 0.9.15 B 模型合同。B 的 User、intent、related、正文及所有原有选项不变；只给 Assistant 主归属增加 `{"kind":"same_unresolved_as_user"}` 并说明何时选用。无标记即不继承。该选项不含参数，也不能用于 User。有效关系仅当同一原始 completion 的 User 是结构严格有效的 `unresolved`、intent 是 `clarify`，且 Assistant 确实声明该选项时成立；不引用上轮、别的 Session、锚点或 Host 的默认值。最终只得到“未决”状态，不获得身份或权限。
- 两臂同题同候选、顺序、Handle 和锚点可见性；对内相同焦点、对间固定种子和不同 ref；正反顺序各 6 对。12 个全新合成样本、24 个独立原生 Session。五个身份待确定：同名、指代不清、撤销发起权、错 Session、有效发起锚点被当前文字明确排除；七个反例：两个真实新目标（有/无锚点）、已知任务的细节澄清、既有工作细化、无任务引用、明确续接和明确切换。有效锚点每臂 5；四个既有目标覆盖四个位置。身份澄清的正文断言要求问号和冻结的关键词组，不能只说以后会问，但不等于自由回答质量评估。
- **模型门槛：** B User、Assistant 原始精确分各 ≥10/12，均不低于 A；B Assistant 至少净多 2 个。五个未决样本 ≥4/5 双角色都正确，且至少四个显式有效关系。七个反例零显式关系尝试（包括被 Host 拒绝的尝试）；两个真实新目标均双角色正确，五个未决样本零合法新目标提案；B 零错误既有指向、零继承已被否定锚点；正文 ≥10/12、不低于 A。
- **Host 门槛：** 24/24 原生完成、独立后端启动、同次账本回执与锚点事实一致；12/12 同对输入上下文完全相同；零泄漏、工具动作、Graph/跨 Journal 变化。离线验证有意标记与 Host fallback 的区别：缺失、非法或非未决来源不能建立关系，非法关系不能通过 Host fallback 得到模型分。零工具的真实模型批次，不测 Streaming、Tool Calling 或 Subagent 的新合同兼容性。
- **预算：** 原 Qwen3-14B Q4_K_M / llama.cpp b12283 Vulkan / stock dsh 0.2.2-rc.1 / RTX 3060 / 27 层 / ctx 2048 / seed 9901 / 温度 0 / 非思考。最多 24 次、每次 1400 输入/320 输出 tokens、合计预留 ≤41,280、120 秒/次、30 分钟/批、单并发、零重试。缺原权重/运行时不替换或下载；回执、泄漏、越界或预算异常停止。
