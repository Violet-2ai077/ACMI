# Phase 0.9.6：最小前文证据配对实验 v1

基点 `830903121965d012a5aa0ba8219aff3c19d63499`。本文件先于样本和实现提交。只做离线合成研究，0.9.4 人工资格和 0.9.5 只读合同结论不变。

## 设计与分区

- 两因素：证据开/关 × literal/contrast 两种确定性解析器。对每个场景，所有单元共用逐字节相同的焦点、候选、排序、Binding、基础包 digest 与预算。证据开时唯一变化是一个由 Host 许可、验证过的完整前一 User turn；关时不读这个来源。两解析器都先保留 0.9.5 现有明确指代结果。literal 接受一个正面命名；contrast 另支持明确的否定对照，若正/反项不能分别对应两个不同已发行候选则弃权。
- 前文投影不选最有利的子串，不提供参考 Task ID 或答案。仅支持同 Workspace、Session、incarnation、上一 cursor、所有非 cursor cut revision 一致的完成 User 正文。需要当前 Scope、显式来源许可和 Host 权威 source digest；按 UTF-8 哈希核对整个原文，再投影。即便原文有很短的有用片段，整句超预算也拒绝，以免裁掉否定、条件或反例。最多 256 UTF-8 bytes 和 96 估算 tokens，整体仍不超过 12288 bytes / 3000 估算 tokens；不得为前文腾位而驱逐候选。
- 构造版本 `acmi-096-evidence-pairs-v1`。36 个目标故事簇（Dev 18 / Validation 18），英文、中文、混合；不随机采样、同一故事及其安全变体不跨 split。参考标签来自新合成 fixture 的独立预期，不来自预测。含直述、对照、间接改述、同名或双指代、焦点引用/条件、历史只读及无关前文；刻意保留当前规则不支持的可解析例，不能只保留词法正例。开发者可见，不是盲集。
- 额外逐案构造 source denied、scope/session/incarnation 不符、revision/cursor 陈旧、正文不完整、摘要伪造、非用户、未完成、预算超限。攻击夹具为合成数据。状态/ACL 改变时关闭结果，不泄漏拒绝来源正文/ID。另验证候选未发行、历史不可切换和明确当前名称胜过旧证据。

## 指标与门槛

- Validation 至少 12 独立故事、10 个可解析正例、4 个应弃权/不建议的负例。报告 2×2 的身份正确率（正例为分母）、有输出精确率、错误选中、澄清/无建议、基础包和候选不变、投影开销。给出 paired wins/losses/ties、净变化百分点及按构造族拆分；同簇安全变体不当独立样本，不报 IID 显著性。
- 在固定 contrast 解析器下，开证据相较关证据的正确正例率净增至少 25 pp，且不得新增错误选中；四单元任何越权来源投影、非预期 ID、候选变化、读禁用来源、历史 ID 用作活跃或写入均为 0。支持切片须有正反控制。分母不足为 INCONCLUSIVE；任一安全条件失败停止。固定证据下两解析器差值只作机制诊断，不要求“更多规则”一定更好。
- 不调用真实模型、凭据、真实 Session、安装 dsh；不改 Core 产品路径、不启用真实反馈、自动绑定、Graph、Apply、Result、Join 或 Task Closure。旧 Holdout/reserve 不读取。通过仅证明受控条件下证据有用，不证明生产可用或 LLM 优劣。未经单独授权不得发任何 Provider 请求。
