# Phase 0.9.10 确定性评分

`score.mjs` 只读冻结输入、程序真值、Host 原生记录和后端票据。独立核对票据唯一性、请求摘要、回复摘要、usage、generation 和来源。分别统计候选选择、归属经过 Host 校验、回答原始字段与原生文本；无法显示的回答不计用户成功。未观测分母为 null，不是 0%。

- coverage：正例中提交既有任务建议的比例；selective accuracy：所有既有身份建议中与真值相同的比例。现有身份错指记 false merge，既有身份被建议为新任务记 false split；相近、关闭、缺失、越权族错指额外单列高风险。
- 回答断言只核对冻结名称的出现与原生 Turn 完成；不能评价文笔、细节、帮助性。多任务只能评分相关集合，不是分段语义或完整 span 准确率。
- 工具动作：验证 lookup 键、真实 ID、结果内容、Task/WorkNode；因果继承不以模型归属是否正确为条件。引用结果时查来源而不查当前 Binding。
- 延迟用 nearest-rank p50/p95。生成延迟包括本地请求前置检查；Turn 延迟按原生调用端到端。C 若运行则合计回答与归属两次生成；Pilot 不计主实验。

评分无网络、不调用 LLM，也不依赖 Adapter 的解码代码。
