# Phase 0.9.15：同次生成相对归属提案（预注册）

基点 `8960d4ad33befa50686a74d7e156ff3c15b20bc0`。0.9.14 说明可信发起上下文能改善续接，但正文正确时仍可生成错误的 `no_task`。本次检验替代合同作为整体，不从中拆分 schema 和措辞的单独效应。

## 唯一实验变量

- A 使用 0.9.14 的原样合同及提示，向模型展示有效 WorkAnchor。B 用互斥提案：`continue_anchor`（仅有有效锚点时允许）、`refer_existing(ref)`、`propose_new(goal)`、`unresolved`（需要确定任务身份）、`no_task`（无工作主题）。两臂都有独立的 User 和 Assistant 主归属，以及相同的 intent、related、正文要求。明确现有任务但缺执行细节的澄清仍归该任务，细化既有任务不创建新目标。
- 同题候选、位置、短 Handle、用户输入、有效锚点和作用域严格相同，模型不见内部 UUID 或真值。保持 0.9.14 受信夹具、启动许可和原生 User 事件校验。A/B 交错、正反顺序各 6；短 Handle 由固定种子派生，既有目标覆盖四个位置。12 个新配对样本，24 个独立原生 Session；合成数据，不用旧结果充数。
- 两个续接（含 whole-task），三种有效锚点冲突（切换、取消、新目标），三个身份不明（同名、撤销发起权、错 Session），另有已知任务的细节澄清、既有任务细化、无锚点新目标、无任务的引用。身份不明和新目标合计五个重点案例。真实模型不挂工具，不测真正流式或 Subagent；只允许每轮一次生成。

- **模型门槛：** B 的 User、Assistant 原始精确分各 ≥10/12；任一角色不比 A 差，两角色正确数合计至少多 2（两角色不是独立样本）；五个重点案例中至少四个双角色原始提案都正确；两个续接双角色均明确用 `continue_anchor`；两臂比较单列覆盖、意图、错指及位置，不用作事后更改门槛。B 零错指既有任务、零继承被当前文本否定的锚点，正文冻结断言 ≥10/12 且不低于 A。B 新提案须包含冻结目标名；不通过无自动路由。小样本仅作为是否进行下一轮原生兼容性测试的依据。
