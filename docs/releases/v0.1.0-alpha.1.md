# ACMI v0.1.0-alpha.1 - First Public Alpha (candidate notes)

This Alpha separates the platform-neutral ACMI Core from host-specific
integrations. A Task UUID survives Session boundaries; explicit Session-local
Binding determines current task context; ambiguous events stay unresolved.
Read-only Task history preserves source information and causal Tool links where
the runtime actually supplies them.

## Try it

From a source checkout with the Node and pnpm versions listed in
[`package.json`](../../package.json):

```sh
pnpm install --frozen-lockfile
pnpm build
pnpm demo
```

The deterministic demo needs no dsh CLI, credentials, or external model. Follow
[Getting Started](../getting-started.md) for the Observer timeline. To integrate
with dsh, follow the [dsh Quick Start](../../examples/dsh-quickstart/README.md)
and its compatibility matrix. The target is Developer Preview `0.2.2-rc.1`, not
an unrestricted range of dsh versions. To write another adapter, use the
[SDK and conformance guide](../adapter-authoring.md) and the
[custom adapter example](../../examples/custom-agent-adapter/README.md).

## Security and known limits

Use the dsh history reader only on a trusted local host, with a fresh Storage
Root dedicated to one Workspace. Zstandard v4 reading is conditional; old
stores are not migrated. Windows hostile filesystem races remain possible.
Observer is read-only and is not a native dsh-context tab. Automatic persistent
Binding is disabled and heuristic attribution remains offline research. No
Claude Code/Codex adapter, general-purpose long-term memory engine, or
production multi-tenant service is included.

Next: qualify additional runtime versions and adapters through conformance,
continue storage isolation research, and evaluate context injection separately
from read-only continuity. See the [Roadmap](../../ROADMAP.md).
