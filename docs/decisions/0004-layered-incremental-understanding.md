# ADR 0004: Preserve layered semantics behind a read-only Understanding boundary

Status: Proposed for Phase 0.9.3; only offline research in Phase 0.9.2.

The archived evaluation conflates intent, identity and structured work; the archive cannot expose the mechanism behind many failures. Keep their outputs separately inspectable and allow each to abstain. Consider a bounded event-triggered hybrid, with typed current observations and explicit revision fences. A hybrid is not an authorization layer: only the existing trusted Host may apply an explicitly confirmed operation, after validation, and Shadow never writes.

Keep a single-pass baseline, a hierarchical control and isolated ablations. The old qualification Holdout is consumed; do not re-evaluate it or select parameters from it. No model comparison claim is supported until new independent double annotation and separately authorized, preregistered real Provider evaluation exist.
