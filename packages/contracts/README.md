# @acmi/contracts

Platform-neutral Session references, explicit Binding events, read-only history, Workspace authorization grants, adapter offers and attribution proposal types. Source references are Session-local; grant minting is reserved to trusted composition. A proposal carries no write authority. Alpha interfaces may evolve before stabilization.

`pnpm --filter @acmi/contracts build` compiles without Node, DOM or dsh declarations. Core and conformance fixtures exercise these contracts.
